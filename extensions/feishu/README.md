# paleoclaw Feishu/Lark

Official paleoclaw channel plugin for Feishu and Lark workplace chats. Community maintained by @m1heng.

Install from paleoclaw:

```bash
paleoclaw plugins install @paleoclaw/feishu
```

Configure the Feishu/Lark app credentials in paleoclaw, then connect the plugin to the chats where agents should receive and send messages.
