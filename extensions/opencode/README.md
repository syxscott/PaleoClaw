# OpenCode Zen paleoclaw provider

Official paleoclaw provider plugin for the OpenCode Zen model catalog, image
understanding, and native OpenCode session browsing.

## Install

```sh
paleoclaw plugins install @paleoclaw/opencode-provider
paleoclaw gateway restart
```

## Docs

See `docs/providers/opencode.md` in the paleoclaw repository, or the published
docs at `https://docs.openclaw.ai/providers/opencode`.
