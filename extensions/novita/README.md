# paleoclaw NovitaAI provider

Official paleoclaw provider plugin for NovitaAI's OpenAI-compatible API.

## Install

```sh
paleoclaw plugins install @paleoclaw/novita-provider
paleoclaw gateway restart
```

## Docs

See `docs/providers/novita.md` in the paleoclaw repository, or the published
docs at `https://docs.openclaw.ai/providers/novita`.
