# paleoclaw LongCat Provider

Official paleoclaw provider plugin for LongCat-2.0 through LongCat's hosted
OpenAI-compatible API.

Install from paleoclaw:

```bash
paleoclaw plugins install @paleoclaw/longcat-provider
paleoclaw gateway restart
```

Configure `LONGCAT_API_KEY`, then select `longcat/LongCat-2.0`.
