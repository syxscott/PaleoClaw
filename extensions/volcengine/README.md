# paleoclaw Volcengine Provider

Official paleoclaw provider plugin for Volcengine models, the Volcengine coding
plan, and Volcengine Speech text-to-speech.

Install from paleoclaw:

```bash
paleoclaw plugins install @paleoclaw/volcengine-provider
paleoclaw gateway restart
```

See <https://docs.openclaw.ai/providers/volcengine> for model and speech setup.
