# paleoclaw Voyage Provider

Official paleoclaw memory embedding provider plugin for Voyage AI.

Install from paleoclaw:

```bash
paleoclaw plugins install @paleoclaw/voyage-provider
paleoclaw gateway restart
```

Set `VOYAGE_API_KEY`, then configure memory search with `provider: "voyage"`.
See <https://docs.openclaw.ai/reference/memory-config> for setup and
configuration.
