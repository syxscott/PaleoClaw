# Slack huddles

Join an active Slack huddle through a dedicated Slack user signed into the paleoclaw Chrome profile. This plugin is disabled by default.

```bash
paleoclaw plugins install @paleoclaw/slack-huddles
paleoclaw plugins enable slack-huddles
```

See https://docs.openclaw.ai/plugins/slack-huddles for setup, modes, audio routing, captions, and limitations.

- Plugin id: `slack-huddles`
- Tool: `slack_huddles`
- CLI: `slackhuddles`
- Package: `@paleoclaw/slack-huddles`
- Minimum paleoclaw host: `2026.7.2`
