# Vercel AI Gateway paleoclaw provider

Official paleoclaw provider plugin for Vercel AI Gateway.

## Install

```sh
paleoclaw plugins install @paleoclaw/vercel-ai-gateway-provider
```

## Docs

See `docs/providers/vercel-ai-gateway.md` in the paleoclaw repository, or the published docs at `https://docs.openclaw.ai/providers/vercel-ai-gateway`.
