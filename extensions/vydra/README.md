# paleoclaw Vydra Provider

Official paleoclaw provider plugin for Vydra image, video, and speech generation.

Install from paleoclaw:

```bash
paleoclaw plugins install @paleoclaw/vydra-provider
paleoclaw gateway restart
```

Set `VYDRA_API_KEY`, then configure an image, video, or speech model. See
<https://docs.openclaw.ai/providers/vydra> for capability details and examples.
