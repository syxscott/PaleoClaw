# Cloudflare paleoclaw plugin

Official paleoclaw plugin for Cloudflare R2 storage locations.

## Install

```sh
paleoclaw plugins install @paleoclaw/cloudflare
```

## Docs

See `docs/plugins/cloudflare.md` in the paleoclaw repository, or the published docs at <https://docs.openclaw.ai/plugins/cloudflare>, for bucket setup, credentials, and storage configuration.
