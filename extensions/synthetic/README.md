# paleoclaw Synthetic Provider

Official paleoclaw provider plugin for Synthetic's hosted Anthropic-compatible
API.

Install from paleoclaw:

```bash
paleoclaw plugins install @paleoclaw/synthetic-provider
paleoclaw gateway restart
```

Configure `SYNTHETIC_API_KEY`, then select a `synthetic/<model-id>` model.

See https://docs.openclaw.ai/providers/synthetic for model and configuration
details.
